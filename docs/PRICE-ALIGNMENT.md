## 统一口径

每个平台、产品、模型只保存一组标准估价。金额保留原币种十进制字符串，不换汇。输入、缓存读取、缓存写入、输出分别核对；缺项不是免费。分时价格在同组 `time_pricing` 中表达，不能把某个平台的时段套到另一平台。

订阅 `usage_prices` 固定为 `not_applicable`，只维护 `reference_prices`；不把套餐额度、积分或月费折成 token 单价。参考顺序为同平台对应型号的公开按量价，再到开发方官网；先查完整官方价表，不以本仓部分收录判断无价。模型身份、窗口、协议与思考控制独立核对，价格来源关系不证明路由等价。

本轮补齐官方明确的缓存写入与峰谷分量，也将失去当前标准价格证据的参考价标为 unknown。仅有限时促销价或尚未生效的未来价格时，不伪造当前非促销标准价；数字与时间保留在逐家证据中。规则详见[估价与多模态计费](PRICING.md)。

## 用户指定的参考关系

- Kimi Code 的 `kimi-for-coding` 保留 K2.8 Preview 身份，按用户指定参考 K2.7 Code，不冒充 K2.8 官方报价。其他 Kimi Code 型号按对应原厂型号分别维护。
- OpenCode Go / Go Plus 的全部型号取模型开发方官网标准按量价，中国厂商使用国内人民币价。Go 用量上限换算表及另一产品的按量余额价不作参考；原厂 API 下线而 Go 仍列出的型号，不能跨产品删除。
- Grok Build 的 `grok-4.7-build-fast` 按用户指定取 xAI 官网单列的 Fast 档；不改成公开 API 请求名。

- 方舟 Seedance 四个系列按既定规则参考同平台最新日期版；千帆仅 Pro 短名继续参考 0813。Flash 短名已正式退役，0731 日期版作为官方替代独立收录。完整身份见各条 `reference_origin.catalog_model`。
