# 后续自动更新

当前交付数据结构、工作规范和校验 / 审阅工具；尚未安装定时 agent、采集器、浏览器登录器或发布器。

1. 按 provider.json 的 sources 定时读取官方资料，建议活跃产品每小时检查、每天完整核对。
2. 价格正文没变只记运行日志；变化才让 agent 阅读和提取，忽略导航 / 广告噪声。
3. 聚合平台按现有catalog逐项核对，新型号先列建议；执行排除清单，SiliconFlow下线型号删除并登记排除，不全量灌入。每天跨峰谷不改价，只在标准基准变化时更新。按AGENTS.md更新具体offering和证据，网络失败不清空模型、不刷新成功日期。
4. 校验后生成一个可审阅批次，明确变动、证据、未知项，按 REVIEW.md 请求一次确认。
5. 无人值守任务以待审核结束；获准后只做指定动作。消费者激活与正式发布另有授权。

来源先官方 API / 机读文档，后网页 / 公告；不要求所有服务商同一种抓法。任务入口见 templates/update-task.md。保留原币种和基准选择，订阅按明确映射独立保存按量参考价：同平台优先、开发方其次；不核对真实扣费。

运行失败、重试、任务费用、待审 PR 属于运行器状态，不放公开目录；凭据、私有合同和账单留在受控系统。公开价目不能证明账号实际扣费，对账由消费者另做。
