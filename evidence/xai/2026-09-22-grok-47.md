## API 逐型号结论

| 请求名 | 可用性 | 上下文 tokens | 输入 / 缓存读 / 输出 USD 每百万 tokens | 思考档位 |
| --- | --- | ---: | --- | --- |
| grok-4.7 | active，9 月 21 日发布 | 500000 | 2 / 0.50 / 6 | low, medium, high, xhigh |
| grok-4.6 | active，旧型号仍有官方条目 | 500000 | 2 / 0.50 / 6 | low, medium, high, xhigh |
| grok-4.5 | active，旧型号仍有官方条目 | 500000 | 2 / 0.30 / 6 | low, medium, high |

每个型号独立核对自身页面；均为 text/image 输入、text 输出，支持工具调用、结构化输出。4.7 的官方说明无独立文本输出限额，`max_output_tokens=null`，不伪造无限大整数。

唯一基准为标准全球 API 且 prompt **严格少于 200,000 tokens**。官方机读型号表和总价表明确达到阈值整次请求进入高价；旧 selection 的“不超过200K”已更正。长上下文 4.7/4.6 为 4/1/12，4.5 为 4/0.60/12；只记备注，不新增并列规则。未改变 4.5/4.6 的原有金额。HTML 泛称“exceed”不覆盖机读明确的 ≥ 边界。地区和服务档溢价不混入全球标准档。公告只有发布日期、没有具体价格生效时刻，因此 effective_from 保持 null。

三者协议为 Chat Completions（legacy）、Responses、原生 gRPC。4.7 型号概览与 Chat 专页给出两个 REST 面，官方 SDK 的精确 4.7 示例结合 gRPC Overview 确认第三面；4.5/4.6 结合各自型号、已有协议证据与官方相同模型范围复核。REST 目录没有 Anthropic Messages 支持依据，不添加该面。4.7 Responses 默认返回加密思考内容，多轮应原样传回，不能误作普通响应文本。

REST 思考默认 high，不能关闭；Chat 的 reasoning_effort 与 Responses 的 reasoning.effort 分开记录。4.5 型号页仍列 xhigh，但思考专页明确其等同 high，保留三档并记冲突。gRPC 原始控制字段未查明，三个型号思考 coverage 仍 partial。
