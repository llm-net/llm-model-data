## 晨羽AI自己写明的内容

- 视频页：「视频生成走厂商协议面：把官方 SDK 的 Base URL 换成对应的子域名、Key 换成平台 API Key，其余一个字都不改」；「不重写路径、查询串、请求体、响应体、HTTP 状态、错误体或任务 ID；不做字段归一」。入口：方舟 `https://ark.api.chenyu.pro` + `/api/v3/...`，百炼 `https://bailian.api.chenyu.pro` + `/api/v1/...`，MiniMax `https://minimax.api.chenyu.pro` + `/v2/...`（H3）。`POST /v1/videos` 已移除。
  - 「火山方舟 Seedance」：「参数与响应以创建视频生成任务、查询视频生成任务与取消或删除任务为准」（链接 82379/1520757、1521309、1521720）；成功结果 `content.video_url` 仅 24 小时有效，Seedance 2.5 最多下载 100 次，任务记录保留 7 天。
  - 「阿里云百炼 万相 3.0」：「参数与响应以万相 3.0 视频生成 API 参考为准」；创建须自带 `X-DashScope-Async: enable`，「平台不代补任何头」；查询 `GET /api/v1/tasks/{id}`，取消 `POST /api/v1/tasks/{id}/cancel`，账号级 `GET /api/v1/tasks` 不开放；任务 ID 与成品地址只保留 24 小时。
  - 「MiniMax H3」：生产唯一 MiniMax 视频模型 `MiniMax-H3`，国内站 `/v2`；示例 `{"model":"MiniMax-H3","content":[{"type":"text",…}],"resolution":"768P","duration":6,"ratio":"16:9"}`；「创建、查询与删除路径和响应均按 MiniMax 官方 H3 文档原样透传」——**无链接**。
  - 「已知限制」：`callback_url` 原样透传、回调由厂商直发，不查询终态的任务不结算。
- 图片页：只写 OpenAI Image 面 `https://api.chenyu.pro/v1` + `POST /images/generations`（`https://chenyu.pro/v1/images/generations` 为兼容别名）；「厂商协议面是否可用以实时目录为准」；「上游字段以火山方舟的图片生成 API为准」（链接 API Explorer）；示例字段 `prompt`、`size`、`response_format`、`watermark`、`image`（URL、Base64 data URI 或其数组）、`sequential_image_generation`、`sequential_image_generation_options.max_images`、`stream`；「网关用 model 选择已绑定的图片渠道，其他已支持的方舟扩展字段会转发给上游」；请求体观察上限 64 MiB；`url` 为上游签名地址；`b64_json`「按上游能力使用」。
- 语音页：`POST /v1/t2a_v2`（同步，含 SSE）、`POST /v1/t2a_async_v2`、`GET /v1/query/t2a_async_query_v2?task_id=…`、`GET /v1/files/retrieve?file_id=…`；同步「参数与响应以 MiniMax 的同步语音合成 HTTP为准」（有链接）；音频默认 hex，`output_format: "url"` 为 24 小时临时地址；流式只支持 hex；异步示例字段 `text`、`voice_setting.voice_id`、`voice_setting.speed`、`audio_setting.format`、`audio_setting.audio_sample_rate`，可先 `POST /v1/files/upload` 再用 `text_file_id`；取回地址「官方注明自生成起 9 小时有效」；「voice_setting.voice_id 可以用 MiniMax 的官方预置音色」，音色复刻 / 设计 / 管理接口不在平台协议面。
- 快速上手「选入口」表与上述一致。

## 采用规则

晨羽AI明确把某份厂商文档指定为「参数与响应以…为准」时，记录该文档对本型号适用的字段与取值，并在每个型号 notes 注明来源是被指定的厂商文档、晨羽AI自身未发布逐型号参数表，状态一律 partial。晨羽AI没有指定的厂商页（MiniMax 异步语音参数表、方舟 Seedance 2.5 样片模式页）不采用。MiniMax H3 虽无链接，但页面点名「MiniMax 官方 H3 文档」并声明原样透传，按 MiniMax 国内站文档索引定位到 V2 创建 / 查询文档采用，并在 notes 说明。

## 冲突

- 图片页「参考图与组图」示例用 `doubao-seedream-5-0-pro-260628` 配 `sequential_image_generation: "auto"`、`max_images: 3`；方舟图片生成 API「模型能力」写 Seedream 5.0 pro「生成单图（不支持配置 sequential_image_generation）」「暂不支持组图生成、联网搜索、流式输出」，且 `sequential_image_generation` / `stream` 的模型支持只列 5.0 lite / 4.5 / 4.0。按晨羽AI指定为准的方舟文档，pro 不记组图与流式参数。
- 实时清单给两款 Seedream 同时列 `ark_image`（slug ark），但图片页只描述 OpenAI Image 面，快速上手的方舟入口只写「火山方舟视频 SDK」；Ark Image 面的路径没有文档依据，未记录该面的操作。
- 方舟 `watermark` 缺省 true，晨羽AI示例传 false；只是示例取值，不构成冲突，写入参数 notes。
- MiniMax 同步文档 emotion 说明：「fluent, whisper 仅对 speech-2.6 生效」，又写「speech-2.8 不支持 whisper」；按较严读法 2.8 不列 fluent 与 whisper。

## 缺项与规范限制

- 所有 10 项为 partial：晨羽AI没有逐型号参数表；厂商参数经被指定文档间接取得，未实调。
- Seedream：方舟另有 `optimize_prompt_options.mode`、`output_format`、`background`、`layer_decomposition`（pro）与 `tools[].type=web_search`（lite），晨羽AI「已支持的方舟扩展字段」未列举，未收录；输出只列 jpeg。
- Seedance：方舟素材 `asset://` 与本账号生成物 / 授权真人素材依赖上游账号，晨羽AI共享上游渠道且未说明；Seedance 1.0 专有 seed / camera_fixed / frames / service_tier 不适用。
- 万相：file / link 素材无 role；有视频输入时 duration 下限与 -1 无法同时表达。
- MiniMax H3：`mm_file://` 引用需平台文件，晨羽AI未说明视频面的文件归属规则，未列入 transports。
- 语音：异步参数表、异步文本上限未被晨羽AI指定；WebSocket 接口与音色复刻 / 设计 / 管理不在晨羽AI协议面；系统音色经共享上游渠道是否逐个可用未确认。
- 文件大小：各来源只写「≤ 30 MB」「不超过 200 MB」等 MB 原文，均未写 MB 与字节的换算关系，按规范不记 `file_size`，原文写入各输入 notes（图片页的「64 MiB」是请求体观察上限，也只写入 notes）。
