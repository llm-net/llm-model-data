## 本轮变化

- API 新增 GPT-6.2 Astra、GPT-6.2 Sol 与滚动请求名 `chat-latest`。GPT-6.2 模型页的总窗口、最大输入、最大输出分别是 1,050,000、922,000、128,000 token，Chat Completions 与 Responses 均可调用，工具仅经 Responses。短上下文 Standard 分别为 8 / 0.4 / 40 / 10 和 2 / 0.1 / 10 / 2.5 USD/百万 token（输入、缓存读、输出、30 分钟写）。模型页另列 12 小时、长上下文和其他速度，保持标准档；11 月 17 日发布与长时背景 beta 的折扣独立。
- `chat-latest` 模型页确认 400,000 总窗口、272,000 最大输入、128,000 最大输出，以及 5 / 0.5 / 30 USD/百万 token；思考控制未公开。11 月 24 日公告确认由滚动快照继续服务。
- Codex 新增同名两条独立记录。当前官方 CLI 0.172.0 静态模型表给默认 272,000（Astra）与 500,000（Sol），都给出 872,000 客户端扩展上限；产品文档的上限只宣布约 1 million。6.1 Terra 的 CLI 默认窗口也明确为 500,000。发行版目录中的 Ultra 是自动委派，单次请求保留 low 至 max 五档；两条新型号的 CLI 默认 low，裸订阅请求的省略默认仍未知。产品页的工作区默认不会覆盖本地 CLI 设定。
- 套餐公开月费 Free 0、Go 8、Plus 20、Pro 100/200/500 USD；补列 Pro 200 与 Pro 500。Pro 200 仅 6.2 Sol 支持 Ultrafast，Pro 500 两款皆可，企业和 Edu 另受工作区许可。不将公告倍率、积分或临时优惠当作 API 现金价。
- 11 月公开更新还列 GPT-Live-1.1、专用医疗配置和仅经批准的审核模型；本产品当前维护一般用途文本 API 清单，专用配置和非文本产品留待单独审阅。Codex 内置图像工具仍为 GPT Image 2，未改用新版 API 图像模型。
