## 语音合成 doubao-seed-tts-2.0（`ark_tts`，Agent Plan）

- 端点 `POST /api/v3/plan/tts/unidirectional`（openspeech.bytedance.com），HTTP Chunked 逐行 JSON，`data` 为 base64 音频块，结束 code 20000000（2516286 HTTP 示例；1598757 2.2–2.3 节）。
- 参数：`audio_params.format` mp3/ogg_opus/pcm 缺省 mp3；`sample_rate` 8000/16000/22050/24000/32000/44100/48000 缺省 24000；`bit_rate` 仅 mp3、默认 64k–160k；`speech_rate`、`loudness_rate` -50–100 缺省 0；`emotion_scale` 1–5 缺省 4；`enable_subtitle`；`additions.*` 按字段表逐项记录（仅 1.0 / 复刻 2.0 适用的字段不记）。
- `speaker`：1257544 两张 2.0 表共 445 个 voice_type（244 个 `*_uranus_bigtts`、201 个 `ICL_uranus_*_tob`），放入 agent-plan-cn 顶层共享取值集 `seed-tts-2-0-voices`（labels 为官方音色名称），参数用 `values_ref` 引用；S2S SC 2.0 的 `saturn_*` 表不属 seed-tts-2.0，未收。1598757 写 `seed-tts-2.0` 只能调用该列表音色。`additions.silence_duration` 单位毫秒（0–30000）。
- 状态 partial（见冲突 3、4 与缺项）。WebSocket 两接口不在 ark_tts 面，只在 notes 提及。

## 冲突

1. 2.5 教程样片 Step2 把 `seed` 列为自动复用参数；1520757 `seed` 的模型支持只列 Seedance 1.0 pro / pro fast。未给 2.x 记 `seed`。
2. `additions.explicit_dialect`：1598757 写仅 Vivi 2.0 支持 dongbei / shaanxi / sichuan；1257544 对 Vivi 2.0 等 4 个音色列粤语、上海、河南、北京、天津、四川、陕西、东北。
3. `audio_params.emotion`：取值只在 1.0 多情感音色表，2.0 音色表未列，本型号可用范围不明。
4. 次要：2.0 系列教程能力表的比例 / 时长未列 adaptive 与 -1；视频生成教程总表 2.5 输出格式只写 mp4、mov 音频编码未列 PCM；均按 API 参考记录。2366394 与 2375486 对 Agent Plan 型号一致。

## 缺项

- 2.0 系列 `duration` 缺省值未写；TTS 文本长度上限、`bit_rate` 缺省值、`section_id` 轮数限制未公布。
- 文件大小：上述文档只写 MB，未给字节数或 MB / KB 换算，按规范不记 `file_size`，原文写进各输入 notes。
- TTS `req_params.additions` 官方类型为 jsonstring，字段路径按其中的键记录。
- 旧来源 `protocol-video`（https://www.volcengine.com/docs/82379/1366799）本次详情接口返回空文档，未改其登记。
