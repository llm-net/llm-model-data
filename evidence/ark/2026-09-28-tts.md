## 协议面 `ark_tts`

- 2516286「流式语音合成」接口表：HTTP POST `https://openspeech.bytedance.com/api/v3/plan/tts/unidirectional`（文档链接为「HTTP Chunked 单向流式文档」）；另有 WebSocket 双流 `wss://…/api/v3/plan/tts/bidirection`、单流 `wss://…/api/v3/plan/tts/unidirectional/stream`。HTTP 示例：请求头 `X-Api-Key`、`X-Api-Resource-Id: seed-tts-2.0`、`X-Control-Require-Usage-Tokens-Return: *`；body `{"req_params":{"text","speaker":"zh_female_vv_uranus_bigtts","audio_params":{"format":"mp3","sample_rate":24000}}}`；`stream=True` 逐行 `json.loads`，`data` base64 解码拼接，`code == 20000000` 结束。
- 1598757 第 2 节「HTTP Chunked格式接口说明」：按量路径 `https://openspeech.bytedance.com/api/v3/tts/unidirectional`；`X-Api-Resource-Id` 决定模型与计费商品（`seed-tts-2.0` → 「语音合成2.0字符版」）；Response Header `Transfer-Encoding: chunked`；body 字段 `req_params.text / ssml / speaker / audio_params / additions`；2.3 节音频响应 `{"code":0,"message":"","data":<base64>}`，结束 `{"code":20000000,"message":"ok","data":null,"usage":{"text_words":10}}`，「usage字段默认不存在，仅在header中插入需要返回用量的标记后会新增」；额外请求头 `X-Control-Require-Usage-Tokens-Return` 可设 `*` 或 `text_words`，「text_words，表示计费字符数」。
- 结论：`ark_tts` 定义为该 V3 HTTP Chunked 单向流式协议（非 OpenAI 兼容）。WebSocket 两种接口使用另一套二进制帧协议（示例需单独的 protocols.py），不并入此面、也未另建面，模型 `interface_assessment` 记 partial。1598757 第 3 节另有 SSE 路径 `/api/v3/tts/unidirectional/sse`，Agent Plan 文档未列对应 `/plan` 路径，不作结论。
