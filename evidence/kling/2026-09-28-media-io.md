## 共同结论

- 当前文档是「新版 API」：型号写在路径末段（如 `POST /text-to-video/kling-3.0`），请求体分 `prompt` 或 `contents[]`、`settings`、`options`。回调协议页写明「模型版本信息位于路径中的是新版，作为 model_name 参数值设置的是旧版」。catalog 的 request_id（`kling-3.0` 等）与新版路径一致。
- 全部操作为 `async_task`：创建返回 `data.id`；`GET /tasks?task_ids=`（或 `external_task_ids=`）查询，`POST /tasks` 按游标批量查询；可选 `options.callback_url` 回调。
- 共同参数：`options.callback_url`、`options.external_task_id`（单用户唯一）、`options.watermark_info.enabled`（缺省 false，开启后另给 `watermark_url`）。
- 图片输入：jpg / jpeg / png，url 或 base64，宽高不小于 300px，宽高比 1:2.5~2.5:1，文件不超过 50MB。
- 产物：`outputs[type=video].url`（防盗链）与 `duration`；「生成的图片/视频会在30天后被清理」，记为 `url_ttl_seconds=2592000`。
- 新版文档中没有 `mode`、`cfg_scale`、`camera_control`、`negative_prompt`、`image_tail`、`static_mask` / `dynamic_masks` 等旧版字段；提示词说明写「可包含正向描述和负向描述」。

## 冲突

- 3.0 Turbo 的提示词上限：文生页写「不能超过 3072 个字符，建议不超过 2500」，图生页写「不超过 2500 个字符」。按页面分别记录。
- O1 时长：能力地图写单镜头文生 / 图生「时长仅5s、10s」；接口页取值为 3~10 秒，只有「仅首帧且无其他参考」时限 5 / 10 秒。按接口页记录取值，并在 notes 标注冲突。
- 2.6 首尾帧：能力地图写「仅1080P且仅无声视频」；接口页只写只支持 1080p。
- 3.0 Omni 的 aspect_ratio 必填条件写「没有首帧图或没有参考视频」，O1 页同一句用「且」。记为条件必填（required=false）并在 notes 保留原文。
- 2026.07.15 公告的新版 API 升级范围没有列 O1，但当前文档已给出 `/omni-video/kling-o1`。按文档记录。

## 缺项（全部模型标 partial 的原因）

- 旧版 API（`model_name` 选型的 `/v1/videos/...`）：公告写「旧版API会持续提供服务，暂无下线计划」，但当前文档索引已不含其参考页，本次未记录。
- 产物容器格式与像素尺寸未写明（清晰度只以 720p / 1080p / 4k 档位表示），`outputs[].formats` 留空。
- 文件大小上限原文为 MB（图片 50MB、Omni 参考视频 200MB、动作参考视频 100MB），没写 MB 是 10^6 还是 2^20 字节，未换算成 `file_size`，只写在 notes。
- contents 型请求只写明 prompt 项内 `text` 必填，没写 contents 是否必须带 prompt 项，记 required=false。动作控制的形象参考图记为必填，但引用主体时能否省略未写明。
- 3.0 Turbo 没有 audio 参数，能力地图标音画同出、价格表只列「有声」档，但没写明是否总是输出有声视频。
- Omni 视频编辑（base_video）的输出时长规则未写明。
- 官方主体、官方音色取值要调列表接口获取，文档没有静态列出，参数记为 `string`。

## 规格表达限制

- MEDIA-IO 没有「主体 / 素材库引用」角色；同一操作内每个 role 只能出现一次，Omni 已用 `reference_image` 表示 `refer_image`。因此 `contents[type=element].element_id` 与 `contents[type=voice].voice_id` 按音色 ID 的惯例记为 `string` 参数，数量与组合规则写在 notes。
- 各 contents 项附带的素材索引 `id`（用于提示词里的 @ 引用）没有单独字段，写在对应输入或参数的 notes 里。
- 数量上限依组合而变（如参考图 + 多图主体合计 ≤7 / ≤4），`max_items` 只能取最大值，条件写在 notes。

## 不属本型号的能力

数字人、对口型、视频特效、多模态视频编辑、文生音效 / 视频生音效在能力地图标「不区分模型版本」，路径里不带这 6 个型号，未写入。主体管理、音色管理是素材管理接口，不是生成操作。
