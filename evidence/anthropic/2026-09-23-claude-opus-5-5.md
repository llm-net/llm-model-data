## Opus 5.5

- 请求 ID `claude-opus-5-5`，官方标注 Latest，2026-09-22 发布，退役不早于 2027-09-22。Opus 5 移入 active legacy，仍是独立型号。
- API 标准价（USD / 百万 token）：输入 4、5 分钟缓存写入 5、1 小时缓存写入 8、缓存命中 0.20、输出 20。脚注 2 明确缓存命中为输入价 0.05 倍，不能按通用 0.1 倍推算。唯一基准沿用 5 分钟写入；Batch 五折、Fast（8 / 40）和 1 小时写入不展开。1M 全窗口按标准价计费。
- 能力：文本与图片输入、文本输出；1M 窗口（十进制记 1000000）；最大输出 128K 未确认精确整数，保留 null。自适应思考始终开启，`thinking.type=disabled` 任何档位都返回 400；`output_config.effort` 支持 low / medium / high / xhigh / max，默认 medium。不支持强制工具调用。
- 协议：Messages 原生；官方 Chat 兼容层示例直接使用该型号，只供评估、功能受限。未发现 Responses。Chat 上的思考控制未登记，思考保持 partial。

## Claude Code

- 模型配置页：`opus` 别名在 Anthropic API、Claude Platform on AWS、Bedrock、Google Cloud Agent Platform 解析到 Opus 5.5；Pro / Max / Team / Enterprise 与 Anthropic API 的 `default` 均为 Opus 5.5。Opus 5.5 需要 v2.1.280 或以上。
- Opus 5.5 的 `--effort` 五档，默认 medium；用户设置文件顶层 `effortLevel` 对它不生效。与 Fable 一样无法关闭思考，会话开关、`alwaysThinkingEnabled` 与 `MAX_THINKING_TOKENS=0` 均无效。
- Extended context：直连 Anthropic API 时 Fable 5.1 / 5、Sonnet 5、Opus 4.7 及以后在所有套餐（含 Pro）以 1M 窗口运行，无需 `[1m]` 变体。据此修正 Opus 5 旧说明中“Pro 需要 usage credits”的写法；窗口数值不变。
- 协议：API formats 表列 Anthropic Messages（`/v1/messages`，可选 count_tokens）及 `anthropic-beta` / `anthropic-version` 头；订阅承载仍只登记 Messages。
- 参考价：Opus 5.5 使用同平台 API 标准价，`catalog_model` 精确指向 `anthropic/api-global/claude-opus-5-5`。
