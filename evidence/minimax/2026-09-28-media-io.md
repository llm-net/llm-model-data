## 结论

- **image-01**（known）：`text_to_image`、`image_to_image`，同为 `POST /v1/image_generation` 同步。prompt ≤1500 字符；aspect_ratio 8 档（含 21:9，默认 1:1）；width / height [512, 2048] 且为 8 的倍数（仅 image-01，aspect_ratio 优先）；response_format url（24 小时）/ base64；n 1–9；seed；prompt_optimizer；aigc_watermark。参考图 `subject_reference[type=character].image_file`：jpg / jpeg / png，<10MB，URL 或 Data URL，指南写每次一张。
- **image-01-live**（partial）：同两个操作；aspect_ratio 7 档（无 21:9），无 width / height；多 `style.style_type`（漫画 / 元气 / 中世纪 / 水彩）与 `style.style_weight`（(0,1]，默认 0.8）。
- **minimax-h3**（partial）：`text_to_video`、`image_to_video`、`reference_to_video`（`POST /v2/video_generation`）与 `video_regeneration`（`POST /v2/video_regeneration`），均为异步任务。text ≤7000 字符（再生成 ≤40000）；resolution 768P / 2K；duration 4–15；ratio（文生必填且非 adaptive，图生恒 adaptive，参考默认 adaptive）；callback_url；aigc_watermark。图片 jpg/jpeg/png/webp/heic/heif ≤30MB、[256,5760] px、宽高比 [0.4,2.5]，首 / 尾帧各 ≤1、参考图 ≤9；参考视频 mp4/mov ≤50MB ≤3 段、单段 2–15 s 总 ≤15 s、23.976–60 fps；参考音频 wav/mp3 ≤15MB ≤3 段。传入方式：公网 URL、`mm_file://{file_id}`、data URI；请求体 ≤64MB。再生成：base_video（24 fps、面积 589,824–1,032,192、宽高被 32 整除、107–362 帧、含音轨）或 `source_task_id`（白名单）二选一，resolution 仅 2K。产物经查询 `task.content.url` 取回。
- **H3-Context-IR**（`POST /v2/h3_context_ir`）：只返回 `task.content.prompt` 文本，未设操作（校验要求每操作至少一个 video 输出），写入 H3 media_io notes。`extra.prompt_expansion_mode` 与 480P 仅属 MiniMax-H3-Max（本目录未收录）。v1 的 prompt_optimizer / fast_pretreatment 不适用 H3。
- **speech-2.8 / 2.6 / 02 hd·turbo**（均 partial）：每型号六个操作——`speech_synthesis`（`POST /v1/t2a_v2` 非流式）、`speech_synthesis_stream`（同路径 stream=true，SSE hex 分块）、`speech_synthesis_websocket`（`WSS /ws/v1/t2a_v2`）、`speech_synthesis_websocket_bidi`（`WSS /ws/v1/t2a_v2_bidi`）、`speech_synthesis_async`（`POST /v1/t2a_async_v2`，text ≤5 万字符）、`speech_synthesis_async_file`（同路径 text_file_id，txt / zip）。流式单列是因为 mode、取回方式与 output_format / aigc_watermark / stream_options / force_cbr / word_streaming 适用范围不同；异步按文本与文件拆开是因为同一角色不能有两个字段。
- 型号差异：emotion——2.6 九个（含 fluent、whisper），2.8 与 02 七个；language_boost——02 去掉 Persian / Filipino / Tamil（38 个），其余 41 个；语气词标签与 WebSocket `continuous_sound` 仅 2.8；异步语气词比同步多 whistles / crying / applause。
- 共享取值集（catalog 顶层 `media_value_sets`）：`minimax-system-voices` 341 个 = 列表页 327 个（labels 取列表页「音色名称」）+ T2A 参考页「部分最新的系统音色」中列表页未收的 14 个（moss_audio_* 8 个、English_Insightful_Speaker、English_radiant_girl、English_Persuasive_Man、English_Lucky_Robot、Japanese_Whisper_Belle、Cantonese_podacast_host_1，无展示名）；文档未按型号区分，六个语音型号共用。`minimax-language-boost-41`（2.8 / 2.6）与 `minimax-language-boost-38`（02，去掉 Persian / Filipino / Tamil）。复刻 / 设计音色不列举；`timbre_weights[].voice_id` 记为 string。
- 输出取回：HTTP 非流式 delivery 为 url 与 hex（缺省 output_format=hex，hex 音频放在 JSON 响应里）；流式与 WebSocket 为 stream（分块内容为 hex）。
- 文件大小：MiniMax 文档只写 MB（图片参考「小于 10MB」、视频输入图片「≤ 30 MB」、参考视频「≤ 50 MB」、参考音频「≤ 15 MB」、请求体「≤ 64 MB」），未给字节换算，均不记 file_size，原文写入对应输入 notes。

## 冲突

1. 图片画风字段：参考页 `style.style_type` / `style.style_weight`；合并版 openapi.json 为 `style.type` / `style.weight`。按参考页记录。
2. image-01-live 图生图：i2i 参考页 model 枚举含 image-01-live；模型概览只写「支持文生图并进行画风设置」。
3. H3 尾帧：content 说明与指南允许只传尾帧；role 说明写 last_frame「需与 first_frame 成对」。
4. emotion：「fluent、whisper 仅对 2.6 生效」与「2.8 不支持 whisper」并列，2.8 的 fluent 不明；按前句未列。
5. 异步文本长度：参考页 text ≤5 万、文件 <100 万字符；异步指南页首「小于 10 万字符」；接口概览「单次最长 100 万字符」。同步：参考页「小于 10000」、指南「最长 10,000」。
6. WebSocket AsyncAPI 把 `timbre_weights` 写成单个对象，HTTP 为数组且说明最多 4 种；按数组记录。
7. 音频格式：请求 format 七种；HTTP 响应 extra_info.audio_format 与 WebSocket 事件说明只列 mp3 / pcm / flac。
8. 系统音色：列表页称「全部」，但参考页另有 14 个 ID 未收；异步指南示例 `audiobook_male_1` 两处都没有，未列入。
9. 模型概览写 H3 Max「仅支持文生 / 图生」，创建接口与接口概览写其支持多模态参考（不影响本目录型号）。

## 缺项与规范无法表达

- WebSocket 参数属于 task_start 事件、text 属于 task_continue 事件，字段路径无法标注事件。
- H3 与图片产物容器格式未写（示例为 .mp4 / .jpeg，未填 formats）；视频 URL 有效期、2K 产物规格、WebSocket 字幕返回字段、流式字幕所在分块、异步结果打包方式与字幕文件格式均未写。
- MiniMax-H3-Max 不在本目录；音色复刻 / 设计 / 管理不属型号生成操作。
