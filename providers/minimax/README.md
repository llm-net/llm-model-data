## 核对重点

国内与国际站独立记录；Token Plan 单独核对。文本、视频、图像和语音计量单位不同。

先读取 provider.json 的官方来源入口；入口本身不代表当前事实已经核实。具体核对状态以 catalog.json 各条 verification 为准。

## 更新纪律

模型身份独立核对；按量产品核价，订阅模型只维护按量参考价：优先本平台，缺价才取开发方。完整重复保存价格，不做运行时继承。只选一个标准基准，其他规格和促销写备注。更新前检查provider.json排除清单。

## 本轮补充

当前 [api-cn](offerings/api-cn/catalog.json) 已放入图像、H3 视频和同步 TTS 样例。H3 输入视频 / 输出视频分项计费，参考图扣免费量；TTS 使用厂商 usage_characters。不要漏掉旧项目出现的 context IR、图像分层等独立操作，也不要因此假定其最新价格已核对。详细口径及未知项见 [PRICING.md](../../docs/PRICING.md)。
